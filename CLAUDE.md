# Working in this repository

## Commit authorship

Every commit is authored by the repository owner. Before the first commit in a
session, set:

```
git config user.name "Mohit Patel"
git config user.email "pmohit645@gmail.com"
```

Commit messages carry no AI attribution: do not add `Co-Authored-By: Claude`,
`Claude-Session:`, or any similar trailer, and do not mention a model name in
commit messages, PR titles or bodies, or code comments.
